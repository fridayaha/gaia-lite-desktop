# 快速开始

UnionAgents 是企业级 AI 智能体平台，支持多引擎接入、统一鉴权、私有化部署。本页带你从零完成第一次调用。

## 1. 登录控制台

打开管理员分发的控制台地址（如 `http://<服务器IP>:30000`），使用分配的账号密码登录。默认情况下只需用户名 + 密码即可登录；当系统检测到账号存在异常登录尝试（连续 2 次密码错误）时，会自动要求填写图形验证码（点击图片可刷新）。

- 平台管理员：全部权限
- 运营人员：智能体管理、监控查看
- 终端用户：终端门户使用智能体（不影响 admin 控制台）

终端门户（enduser）登录页支持 4 种登录方式：

- **账号密码**：用户名 + 密码
- **邮箱登录**：已验证邮箱 + 密码
- **手机号登录**：已验证手机号 + 密码
- **短信验证码登录**：手机号 + 短信验证码（仅当系统开启 SMS 渠道时显示）

点击登录页右下角「忘记密码？」可重置密码：选择邮箱或短信渠道 → 输入邮箱/手机号 + 图形验证码 → 接收验证码 → 输入 6 位验证码 → 设置新密码。

安全策略：

- **图形验证码（条件触发）**：默认登录不要求验证码；同一账号连续 2 次密码错误后，第 3 次起会要求填写图形验证码，验证码 5 分钟有效，校验后立即失效（一次性）。
- **账号锁定**：同一账号连续 5 次密码错误会被锁定 15 分钟，期间登录会提示「账号已锁定，请 X 分钟后重试」。
- **IP 限流**：同一 IP 每分钟尝试超过 10 次会触发限流，每小时失败超过 50 次会临时封禁 1 小时。

登录后进入 Dashboard，可看到智能体总数、调用次数、活跃实例等概览。

## 2. 创建智能体

### 2.1 发布智能体定义

1. 进入「智能体管理 → 智能体定义」
2. 点击「创建」按钮，填写名称、选择引擎类型（Hermes / Dify / OpenClaw 等）
3. 配置 Persona（人设）、Skills（技能）、Model（模型）等参数
4. 点击「发布」 — 定义变为 `PUBLISHED` 状态，可供实例化

### 2.2 创建智能体实例

1. 进入「智能体管理 → 智能体实例」
2. 点击「创建」，选择已发布的智能体定义，选择所属用户组
3. 填写实例名称，点击保存
4. 在实例列表点击实例名进入详情页

### 2.3 部署实例

1. 在实例详情页点击「部署」按钮
2. 等待 Pod 启动（状态变为 `RUNNING`）
3. 部署完成后可通过终端门户或 API 调用

## 3. 调用智能体

有两种调用方式：

### 3.1 终端门户

访问终端门户地址（如 `http://<服务器IP>:30081`），选择智能体后直接对话。适合人工交互场景。

### 3.2 API 调用

在智能体详情页「API Keys」tab 创建 `sk-` 风格 API Key，用标准 OpenAI SDK 调用。详见 [API 调用指导](./api-usage)。

## 4. 接入 IM 渠道（可选）

如需将智能体接入企微/飞书等 IM 平台：

1. 在实例详情页「渠道」tab 配置 webhook
2. 按 [IM 渠道架构](../architecture/architecture-im-channels) 文档完成平台侧配置
3. IM 用户 @机器人 即可触发智能体响应

## 5. 监控与运维

- **监控中心**：链路追踪 / 用量分析 / 调用分析 / 异常告警，查看智能体运行情况
- **操作记录**：记录所有 admin 操作（创建/部署/删除等），支持审计
- **服务日志**：manager / gateway 服务日志可在线查看
