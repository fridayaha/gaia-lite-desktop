# 技能工作室

技能工作室（Skill Studio）是平台的在线技能开发环境。你可以在浏览器里创建技能、与一个开发引擎对话让它生成/修改技能文件、实时调试、校验打包，并一键发布到能力中心走审核流程——无需本地搭建开发环境。

## 入口

在左侧导航栏单击**技能开发**（位于「智能体模版」下方的一级菜单），进入技能工作区列表页。

## 创建技能工作区

1. 在技能工作室列表页，单击右上角**创建技能**。
2. 填写**工作区名称**（如「图表绘制技能」）和**简要描述**，单击**创建并开发**。

进入工作区详情页后，开发引擎会自动启动。

## 工作台三栏

详情页分为三栏：

- **左栏 · 技能配置**：展示 `manifest.json` 与 `SKILL.md` 的元数据摘要。单击**编辑配置**可在线编辑这两个文件（manifest 需含 `type: "skill"`）。
- **中栏 · 对话**：与开发引擎对话。顶部「开发 / 调试」两个 Tab：
  - **开发**：用于让引擎帮你创建/修改技能文件（具备读写、bash 等工具）。
  - **调试**：用你编写的 `SKILL.md` 作为技能，验证技能行为（只读工具，不会改文件）。
- **右栏 · 文件**：工作区文件树 + 在线代码编辑器。工具改动过的文件会标 🟢新增 / 🟡修改。

## 让引擎开发技能

在「开发」Tab 的输入框描述需求，例如「创建一个图表绘制技能，包含 SKILL.md 和 manifest.json」。引擎会调用工具（write/edit/bash/grep 等）生成文件，工具调用以可折叠卡片形式显示在回复中：

- **write**：展示路径 + 写入内容
- **edit**：展示路径 + 改动 diff（增删行着色）
- **bash**：展示命令 + 输出
- **ls / read / grep**：展示路径或匹配结果

文件改动后，右侧文件树自动刷新；底部可单击**终端**查看所有 bash 命令的聚合输出。

## 在线编辑文件

在右栏文件树单击文件，用内置代码编辑器（支持 Markdown / JSON 语法高亮）直接编辑：

- 修改后**保存**按钮高亮，单击保存写入工作区。
- 切换文件时有未保存改动会提示。
- 顶部**新建文件** / **上传文件**按钮可添加文件。

编辑 `SKILL.md` / `manifest.json` 后，切到「调试」Tab 单击**重载技能**让调试引擎重新加载技能定义（无需重启）。

## 校验、打包、发布

详情页顶部三个按钮：

1. **校验**：检查 `SKILL.md` frontmatter（name/description/version/author）与 `manifest.json`（name/version/author/description/engine/type=skill）是否完整合规。
2. **打包**：把工作区打成 zip 下载（自动排除引擎内部目录）。
3. **发布**：打包并上传到能力中心，自动安全扫描后创建草稿版本。发布弹窗显示：
   - 风险等级（低/中/高/阻断）与发现项列表
   - 阻断级风险需在能力中心处理后方可发布

发布成功后，能力中心会出现该技能的草稿版本，你在能力中心走「提交审核 → 批准 → 发布」流程即可让其他用户订阅。

## 调试技能

切到「调试」Tab：

1. （可选）编辑 `SKILL.md` 后单击**重载技能**让其生效。
2. 在输入框发送消息，调试引擎会用你的技能定义回复。
3. 调试引擎只有只读工具，不会修改技能文件，可安全验证技能行为。

## 预期结果

- 创建工作区后，开发引擎自动就绪（状态标签 `ready`）。
- 发送消息后，回复逐字流式渲染，工具调用以卡片展示。
- 重载页面后，历史对话（含工具调用）完整保留。
- 发布后，能力中心出现该技能草稿，扫描结果显示风险等级。
