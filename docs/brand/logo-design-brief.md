# 知行 · UnionAgents Logo 设计需求

## 品牌信息

- **中文名**: 知行
- **英文名**: UnionAgents
- **Slogan**: 知行合一 · 智能体平台 / Unity of Knowledge and Action
- **定位**: 企业级多智能体平台
- **核心理念**: "知"（知识、思考、模型）+ "行"（行动、执行、工具）= 知行合一

## Logo 设计要求

### 风格
- 现代、简洁、科技感、企业级
- 适合作为 Web 应用 favicon（需能缩放到 64×64 清晰可辨）
- 可包含抽象图形 + 文字组合

### 核心元素
1. **两条交互动感弧线** — 代表"知"与"行"的交汇融合
2. **中心节点** — 代表 AI 智能体核心
3. **网络/连接点** — 代表企业级分布式多智能体
4. 整体形状可以是圆形、盾形或六边形

### 配色
- 主色: 深蓝 → 靛紫渐变（`#4F6CF7` → `#7C3AED`）
- 辅色: 青蓝（`#06B6D4`）
- 背景: 深色模式适配（透明或深色底）
- 氛围: 科技感、专业、可信赖

### 参考意象
- 神经元 / 神经网络节点
- 无限符号（∞）的变体
- 太极图阴阳交互的抽象表达
- 交汇的轨道 / 流线

## English Prompts for AI Image Generation

### Prompt 1 — Minimalist Tech Logo

```
A minimalist tech logo for "UnionAgents — 知行" (Enterprise AI Agent Platform).

The logo should feature two intersecting flowing arcs forming an abstract circle:
- One arc in deep blue-to-purple gradient (#4F6CF7 → #7C3AED) representing "Knowledge" (知)
- One arc in teal-to-blue gradient (#06B6D4 → #4F6CF7) representing "Action" (行)
- A small bright dot at their intersection representing the AI agent core

Style: clean, modern, enterprise, suitable for SaaS platform
Shape: circular emblem, scalable to favicon size (64×64)
Background: transparent
Mood: professional, intelligent, trustworthy, cutting-edge

Negative prompt: no Hermes staff, no Greek mythology, no cartoon, no 3D render, no glossy effects, no gradients with more than 3 stops
```

### Prompt 2 — Abstract Geometric Mark

```
Abstract geometric logo mark for "UnionAgents" — an enterprise multi-agent AI platform.

The central concept is "Unity of Knowledge and Action" (知行合一):
- Two sweeping ribbon-like forms intertwine to create a dynamic "U" or infinity-like shape
- Upper ribbon: deep indigo (#4F6CF7), representing knowledge/reasoning
- Lower ribbon: teal (#06B6D4), representing action/execution
- A small diamond node at the center where they intersect
- Subtle dot-connector elements suggesting networked AI agents

Format: SVG-style flat vector, solid colors, precise geometry
Style: modern enterprise, B2B SaaS, AI technology
Usage: web app logo, favicon, login page

Negative prompt: no photorealistic, no shadows, no bevel, no gradients, no serif fonts
```

### Prompt 3 — Wordmark + Symbol

```
A combination logo with a symbol mark and wordmark for "知行 · UnionAgents".

Symbol: An abstract hexagonal or circular mark with two interlocking flowing paths
that form both an "A" (for Agent) and a unity knot. A node at center.

Typography: "知行" in a modern Chinese sans-serif (like Noto Sans SC or PingFang SC)
on the first line, "UnionAgents" in a clean geometric sans-serif (like Inter or SF Pro)
on the second line, smaller and lighter weight.

Colors: Deep blue (#1E3A5F) to indigo (#4F6CF7) gradient
Style: sophisticated, enterprise, AI technology
Use case: website header, product UI, marketing materials

Negative prompt: no clip art, no clipart, no stock icon, no complex detail, no花纹
```
