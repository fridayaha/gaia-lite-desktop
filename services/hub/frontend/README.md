# Hub Frontend

PoC 基础管理前端。

## 本地启动

```bash
cd frontend
npm install
npm run dev
```

默认访问 `http://localhost:5173`，API 请求代理到 `http://localhost:8000`。

## 页面

| 路径 | 说明 |
|------|------|
| `/items` | 能力列表（筛选/创建/预置初始化） |
| `/items/:id` | 能力详情（版本管理/生命周期操作） |

## 演示链路

1. 在列表页点击"初始化预置"，创建 4 类样例
2. 点击任一能力进入详情页
3. 创建版本 → 扫描 → 提交版本审核 → 审批通过 → 发布版本
4. 验证 blocking 风险：创建含 `rm -rf` 的 config，扫描后审批会返回 400
5. 发布两个版本后，回滚到旧版本
6. 禁用能力后，详情页仍可访问

> 当前 PoC 不启用资产级审核。资产发布由版本发布联动完成（publish 版本时自动将资产状态设为 published）。"提交资产审核"属于后续资产级上架审核能力预留，当前前端不展示。

## 导入能力包

列表页点击"导入能力包"按钮，选择 manifest 文件上传。

支持格式：`.json` / `.yaml` / `.yml` / `.zip`（zip 内需包含 manifest）

导入后资产状态为 `draft`，需要手动走完整流程：
创建版本 → 扫描 → 提交审核 → 审批通过 → 发布
